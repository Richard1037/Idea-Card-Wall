# 灵感卡片墙 — 产品设计文档

## 1. 产品定位

一个轻量、纯粹的灵感记录与回顾工具。用户随手记录灵感、金句、语录，所有卡片在页面上以横向传送带形式自动滚动展示，随时翻阅、随时检索。

## 2. 核心功能

### 2.1 卡片管理

| 功能 | 描述 |
|------|------|
| 新建 | 点击 "+" 按钮弹出新建表单，输入标题、正文、来源、标签、背景色 |
| 编辑 | 点击卡片详情弹窗中的编辑按钮，修改任意字段 |
| 删除 | 卡片详情弹窗中出现删除按钮，点击后弹出二次确认对话框，确认后永久删除 |
| 搜索 | 顶部搜索框，输入关键词实时过滤卡片，匹配关键词在卡片上高亮显示 |
| 标签筛选 | 顶部标签栏，点击标签筛选该标签下的卡片，支持多选 |

### 2.2 传送带展示

- 所有卡片在页面主体区域横向排列，自动向左匀速滚动
- 鼠标悬停在卡片上时滚动暂停，移开后恢复
- 速度分三档：慢 / 中 / 快，顶部控制栏可切换
- 排序支持切换：按创建时间 / 按修改时间

### 2.3 卡片详情

- 点击卡片弹出居中模态框，深色毛玻璃背景
- 展示完整标题、正文、来源、标签、创建/修改时间
- 模态框内提供编辑和删除操作入口

### 2.4 数据持久化

- 所有数据存储在浏览器 localStorage
- 暂无导入导出功能

## 3. 数据结构

### 3.1 卡片对象

```typescript
interface Card {
  id: string;                    // 唯一标识，UUID
  title: string;                 // 标题（必填）
  content: string;               // 正文（必填）
  source: string;                // 来源（选填）
  tags: string[];                // 标签数组
  backgroundColor: string;       // 纯色背景色 or 渐变起始色
  backgroundGradient: {
    enabled: boolean;            // 是否启用渐变
    color1: string;              // 渐变起始色
    color2: string;              // 渐变结束色
    angle: number;               // 渐变角度 0-360
  } | null;
  createdAt: number;             // 创建时间戳
  updatedAt: number;             // 修改时间戳
}
```

### 3.2 全局设置

```typescript
interface AppSettings {
  defaultBackgroundColor: string;        // 全局默认纯色背景
  defaultGradient: {
    color1: string;
    color2: string;
    angle: number;
  };
  scrollSpeed: 'slow' | 'medium' | 'fast';  // 滚动速度档位
  sortBy: 'createdAt' | 'updatedAt';        // 排序方式
}
```

### 3.3 localStorage 存储结构

```
ideacardwall_cards: Card[]          // 所有卡片数据
ideacardwall_settings: AppSettings  // 全局设置
ideacardwall_tags: string[]         // 已使用的标签池（用于标签建议）
```

- **底部状态栏**：卡片总数统计 + 全局设置入口

## 5. 视觉设计规范

### 5.1 设计风格

- **主题**：深色系 + 玻璃质感（Glassmorphism）
- **整体基调**：沉稳、内敛、有质感，避免轻浮
- **禁止事项**：蓝紫渐变、大面积彩色渐变、过度装饰

### 5.2 色彩体系

| 用途 | 颜色 | 说明 |
|------|------|------|
| 页面背景 | `#0f0f14` 深炭黑 | 主背景色，接近纯黑但不死板 |
| 卡片默认背景 | `#1a1a24` 或 `rgba(255,255,255,0.06)` | 带玻璃半透明感 |
| 卡片边框 | `rgba(255,255,255,0.08)` | 微妙的玻璃边缘光 |
| 卡片阴影 | `0 8px 32px rgba(0,0,0,0.4)` | 增强层次感 |
| 卡片悬停 | 轻微上浮 + 边框亮度提升 | 微交互反馈 |
| 主文字 | `#e8e8ed` 浅灰白 | 高可读性 |
| 次要文字 | `#909098` 中灰 | 来源、时间等辅助信息 |
| 强调色 | `#5eead4` 青绿 | 标签、高亮、按钮状态（避免蓝紫） |
| 模态框背景 | `rgba(0,0,0,0.6)` + `backdrop-filter: blur(12px)` | 毛玻璃遮罩 |

### 5.3 卡片尺寸

- 宽度：280px，高度：200px（预览态）
- 圆角：16px
- 内边距：20px
- 卡片间距：16px
- 标题最大显示 2 行，正文最大 4 行，超出省略

### 5.4 字体

- 系统默认中文字体栈：`"PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", sans-serif`
- 标题：16px / 600 字重
- 正文：14px / 400 字重
- 来源：12px / 400 字重 / 次要文字色

### 5.5 动效

- 卡片悬停：`transform: translateY(-4px)` + 边框亮度提升，过渡 0.3s ease
- 模态框打开：缩放 + 淡入，0.25s ease-out
- 传送带滚动：CSS animation / requestAnimationFrame 匀速
- 新建/删除：卡片滑入/滑出动效

## 6. 交互流程

### 6.1 新建卡片

```
[点击 + 新建按钮] → [弹出模态框表单]
  ├── 标题输入框（必填）
  ├── 正文输入框（必填，多行 textarea）
  ├── 来源输入框（选填）
  ├── 标签输入（输入 + 回车添加，已有标签建议）
  ├── 背景色设置
  │   ├── 纯色：颜色选择器
  │   └── 渐变：起始色 + 结束色 + 角度滑块（0-360°）
  └── [取消] [保存]
```

### 6.2 查看/编辑/删除卡片

```
[点击卡片] → [弹出详情模态框]
  ├── 完整展示标题、正文、来源、标签、时间
  ├── [编辑] → 表单模态框，预填当前数据
  └── [删除] → 二次确认弹窗
       ├── [取消]
       └── [确认删除] → 删除卡片，关闭弹窗
```

### 6.3 搜索与过滤

```
[输入搜索关键词] → 实时过滤（节流 300ms）
  ├── 匹配范围：标题 + 正文 + 来源
  ├── 匹配卡片在传送带中显示，不匹配的隐藏
  └── 匹配关键词在卡片上高亮显示（<mark> 标签）
```

### 6.4 标签筛选

```
[点击标签] → 筛选该标签下的卡片
  ├── 支持多选（点击多个标签，取并集）
  ├── 再次点击已选标签取消选中
  └── 标签筛选与搜索关键词叠加（AND 逻辑）
```

## 7. 技术方案

### 7.1 技术栈

- 纯前端三件套：HTML + CSS + JavaScript（无框架）
- 无构建工具，无依赖，单个 HTML 文件即可运行
- 数据持久化：localStorage

### 7.2 核心实现要点

| 模块 | 实现方案 |
|------|----------|
| 传送带滚动 | CSS `animation` 或 `requestAnimationFrame` 驱动 `transform: translateX()` |
| 悬停暂停 | `animation-play-state: paused` 或标志位控制 |
| 卡片渲染 | JavaScript 动态生成 DOM，数据变化时重新渲染 |
| 搜索高亮 | 正则匹配后替换为 `<mark class="highlight">` 标签 |
| 毛玻璃效果 | `backdrop-filter: blur()` + 半透明背景 |
| 颜色选择器 | `<input type="color">` 原生控件 |
| 渐变设置 | 两个颜色选择器 + 角度 `<input type="range">` 预览 |
| localStorage | JSON 序列化存储，读写封装 |

## 8. 边界情况与状态

### 8.1 空状态

- 无卡片时，传送带区域显示引导文案："还没有灵感卡片，点击 + 创建第一张吧"
- 搜索无结果时，显示："没有找到匹配的卡片"

### 8.2 极限情况

- 单张卡片：传送带不滚动（或原地静止）
- 卡片数量少（< 可视区域宽度）：居中显示，不滚动
- 卡片内容过长：预览态截断省略，详情模态框完整显示（可滚动）
- 标签过多：标签栏超出时横向滚动

### 8.3 数据安全

- 删除操作二次确认，防止误删
- 存储前校验数据完整性
- localStorage 读取失败时降级为空数组
