# 灵感卡片墙 (Idea Card Wall)

一个轻量、纯粹的灵感记录与回顾工具，以横向传送带形式自动滚动展示你的灵感卡片。

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-1.0.0-green.svg)

## ✨ 功能特性

### 📝 卡片管理
- **新建卡片** - 支持标题、正文、来源、标签、自定义背景色/渐变
- **编辑卡片** - 随时修改任意字段
- **删除卡片** - 二次确认机制，防止误操作
- **数据持久化** - 所有数据自动保存至浏览器 localStorage

### 🔍 搜索与筛选
- **全文搜索** - 支持搜索标题、正文、来源，关键词高亮显示
- **标签筛选** - 点击标签快速筛选，支持多选组合过滤
- **实时响应** - 输入即搜索，300ms 节流优化

### 🎬 传送带展示
- **自动滚动** - 所有卡片横向排列，匀速向左自动滚动
- **悬停暂停** - 鼠标悬停时自动暂停，移开后恢复
- **拖拽浏览** - 支持鼠标拖拽快速翻阅
- **无缝循环** - 三组卡片首尾相连，无限循环滚动
- **速度控制** - 慢 / 中 / 快三档可调
- **排序切换** - 支持按创建时间或修改时间排序

### 🎨 视觉体验
- **深色主题** - 沉稳内敛的深色系界面
- **玻璃质感** - Glassmorphism 毛玻璃效果
- **扫描线背景** - 基于 WebGL 的动态扫描线特效
- **微交互** - 卡片悬停上浮、模态框缩放淡入等细腻动效
- **自定义外观** - 支持纯色/渐变背景，角度可调

## 🚀 快速开始

### 方式一：直接打开（推荐）
最简单的方式，无需任何安装：

1. 下载本项目
2. 双击 `index.html` 在浏览器中打开即可使用

### 方式二：本地服务器
如需完整功能（避免浏览器安全限制）：

```bash
# 使用 Python
python -m http.server 8080

# 或使用 Node.js
npx serve .

# 或使用 PHP
php -S localhost:8080
```

然后访问 `http://localhost:8080`

## 💡 使用指南

### 创建你的第一张卡片
1. 点击右上角 **"+ 新建卡片"** 按钮
2. 填写标题和正文（必填项）
3. 可选填写来源、添加标签
4. 选择喜欢的背景颜色或渐变效果
5. 点击 **"保存"**

### 管理卡片
- **查看详情** - 点击任意卡片打开详情弹窗
- **编辑** - 在详情弹窗中点击 **"编辑"**
- **删除** - 在详情弹窗中点击 **"删除"**，确认后永久移除

### 搜索与筛选
- 在顶部搜索框输入关键词，卡片会实时过滤并高亮匹配内容
- 点击顶部标签栏中的标签进行筛选，支持同时选择多个标签
- 排序方式和滚动速度可在控制栏调整

### 全局设置
点击底部状态栏右侧的 ⚙ 图标进入设置：
- 设置新卡片的默认背景色
- 启用/禁用默认渐变效果
- 配置默认渐变的颜色和角度

## 🎯 数据结构

### 卡片对象
```typescript
interface Card {
  id: string;                    // 唯一标识
  title: string;                 // 标题（必填）
  content: string;               // 正文（必填）
  source?: string;               // 来源（选填）
  tags: string[];                // 标签数组
  backgroundColor: string;       // 背景色
  backgroundGradient?: {         // 渐变配置
    enabled: boolean;
    color1: string;
    color2: string;
    angle: number;
  };
  createdAt: number;             // 创建时间戳
  updatedAt: number;             // 修改时间戳
}
```

### localStorage 存储
```
ideacardwall_cards    → Card[]          // 卡片数据
ideacardwall_settings → AppSettings     // 全局设置
ideacardwall_tags     → string[]        // 标签池
```

## 🌈 视觉设计

### 设计理念
- **沉稳内敛** - 深色基调，避免过度装饰
- **清晰层次** - 通过透明度、阴影建立空间关系
- **克制用色** - 以青绿色 (#5eead4) 作为唯一强调色
- **流畅动效** - 所有过渡均采用 ease 曲线，时长 0.25s-0.3s

### 色彩体系
| 用途 | 颜色值 | 说明 |
|------|--------|------|
| 页面背景 | `#0f0f14` | 深炭黑 |
| 卡片背景 | `#1a1a24` | 深灰蓝 |
| 主文字 | `#e8e8ed` | 浅灰白 |
| 次要文字 | `#909098` | 中灰 |
| 强调色 | `#5eead4` | 青绿 |
